## 📂 Repository Structure

The project is organized into domain-specific modules, each containing documented code and logic for complex engineering problems:

### 🤖 Machine Learning (ML)
* **Focus:** Implementing supervised and unsupervised models for predictive analysis.
* **Key Tasks:** Linear & Logistic Regression, K-Means Clustering, and Neural Network implementations.
* **Stack:** Python, Scikit-learn, Pandas, Jupyter Notebooks.

### ⛓️ Blockchain Technology
* **Focus:** Developing decentralized logic and secure smart contracts.
* **Key Tasks:** Student data management on-chain and peer-to-peer transaction logic.
* **Stack:** Solidity, Remix IDE, Ethereum Framework.

### 🧩 Design & Analysis of Algorithms (DAA)
* **Focus:** Mathematical optimization and algorithmic efficiency.
* **Key Tasks:** 0/1 Knapsack (DP vs. Branch & Bound), Huffman Coding (Greedy), N-Queens (Backtracking), and Quicksort Analysis.
* **Stack:** C++, Java.

### 🛡️ Cyber Security & Digital Forensics (CSDF)
* **Focus:** Cryptographic security and forensic investigation techniques.
* **Key Tasks:** Data encryption/decryption, digital signatures, and mini-project on forensic recovery.

### 🔍 Information Retrieval (IR)
* **Focus:** Data indexing and search engine mechanics.
* **Key Tasks:** Inverted index construction, Boolean models, and ranking algorithms.
